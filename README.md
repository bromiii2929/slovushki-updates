# Словушки

В [GitHub Releases](https://github.com/bromiii2929/slovushki-updates/releases) доступны выпуски приложения для Android и Android TV.

Файл `updates.json` указывает на текущий APK. Для новой версии добавьте подписанный APK и его `updates.json` в один коммит ветки `main`. Увеличьте `versionCode` и подпишите APK прежним ключом.
